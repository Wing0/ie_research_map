# IE Research Map

## Purpose
**IE Research Map** is a comprehensive tool designed to map, analyze, and monitor the landscape of research and organizations focused on **child and adolescent health in developing countries**. 

It automates the process of:
1.  **Profiling Organizations**: Gathering and summarizing information about relevant organizations using AI and web scraping.
2.  **Monitoring Clinical Trials**: Tracking new clinical trials from ClinicalTrials.gov, assessing their relevance using AI, and notifying via Slack.
3.  **Monitoring News**: Tracking global news events, filtering for relevance, and summarizing them for Slack notifications.
4.  **Knowledge Extraction**: Enabling a Q&A system where users can ask specific questions about the profiled organizations, with answers generated by AI.

## Features

*   **Organization Profiling**:
    *   Compiles detailed profiles including summaries, recent initiatives, and relevance scores.
    *   Uses Google Search to gather data and AI (GPT-4o, Gemini, Llama 3) to synthesize it.
*   **Clinical Trials Intelligence**:
    *   Fetches latest trials from **ClinicalTrials.gov API v2**.
    *   Filters trials based on specific medical conditions.
    *   Uses AI to score trials based on relevance to child/adolescent health and global health.
    *   Generates bullet-point summaries of trial descriptions and results.
*   **News Monitoring**:
    *   Integrates with **NewsRegistry** to fetch global news.
    *   Scores news events for relevance to specific concepts.
    *   Visualizes relevance distribution.
*   **Interactive Q&A**:
    *   CLI interface to ask questions about organizations.
    *   AI formulates the question, determines the data type of the answer, and queries the knowledge base.
*   **Slack Integration**:
    *   Automated notifications for high-relevance clinical trials and news.
*   **Multi-Model AI Support**:
    *   Intelligent routing between **OpenAI (GPT-3.5/4o)**, **Google Gemini Pro**, and **Meta Llama 3** (via Replicate) based on prompt complexity and token count.

## Installation

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd ie_research_map
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: If `requirements.txt` is missing, you will need packages like `requests`, `beautifulsoup4`, `googlesearch-python`, `openai`, `tiktoken`, `python-decouple`, `matplotlib`, `replicate`, `google-generativeai`)*

3.  **Configuration**:
    Create a `.env` file in the root directory with the following keys:
    ```env
    OPENAI_API_KEY=your_openai_key
    GOOGLE_API_KEY=your_google_gemini_key
    REPLICATE_API_TOKEN=your_replicate_key
    NEWSREGISTRY_API_KEY=your_newsregistry_key
    SLACK_WEBHOOK_URL=your_slack_webhook_url
    ```

## Usage

### Main Interface
The primary entry point for the application is `main.py`. This CLI tool allows you to investigate organizations and conditions.

```bash
python main.py
```

**Menu Options:**
*   **Investigate organizations**:
    *   *Ask a question*: Query the database of organizations.
    *   *Complete data*: Fill in missing answers for existing questions.
    *   *Update profiles*: Batch analyze organizations listed in `players.txt`.
    *   *Parse clinical trials data*: Update organization profiles with trial data.
*   **Investigate conditions**:
    *   *Find trials for conditions*: Fetch and update trial data for conditions defined in `conditions.json`.

### Clinical Trials Monitor
To run the clinical trials monitor independently (e.g., as a cron job):

```bash
python trials.py
```
*This script checks for new trials, scores them, and posts high-relevance ones to Slack.*

### News Monitor
To run the news monitor:

```bash
python news.py
```
*This script fetches latest news, assesses relevance, and posts to Slack.*

## Architecture & How It Works

### 1. AI Integration (`ai_apis.py`)
The system uses a `DynamicAI` class to manage interactions with Large Language Models. It automatically selects the most cost-effective and capable model based on the task:
*   **Token Counting**: Uses `tiktoken` to estimate prompt size.
*   **Model Selection**:
    *   **Llama 3**: For simple, short prompts.
    *   **GPT-3.5 Turbo**: For moderate tasks.
    *   **GPT-4o**: For complex reasoning or high-stakes summaries.
    *   **Gemini Pro**: For very long contexts (up to 30k+ tokens).

### 2. Data Sources
*   **ClinicalTrials.gov**: Accessed via `https://clinicaltrials.gov/api/v2/studies`.
*   **NewsRegistry**: Accessed via `http://eventregistry.org/api/v1/article/getArticles`.
*   **Google Search**: Used via `googlesearch-python` to "read" about organizations.

### 3. Data Storage
Data is primarily stored in local JSON files:
*   `profiles_gemini.json`: Stores organization profiles and Q&A data.
*   `trials/trials.json`: Archive of fetched clinical trials.
*   `trials/conditions.json`: Configuration of medical conditions to monitor.
*   `news/slack_posts.json`: History of posted items to prevent duplicates.

### Clinical Trials API (`trials.py`)
Fetching trials for a specific condition.

```python
import requests

def get_trials(condition, page_size=10):
    url = "https://clinicaltrials.gov/api/v2/studies"
    params = {
        "query.cond": condition,
        "pageSize": page_size,
        "format": "json"
    }
    response = requests.get(url, params=params)
    return response.json()

# Example usage
data = get_trials("Malaria")
for study in data.get('studies', []):
    print(study['protocolSection']['identificationModule']['nctId'])
```

### Slack Webhook (`utils.py`)
Posting a formatted message to Slack.

```python
import requests
import json
from decouple import config

def post_to_slack(message_text):
    url = config("SLACK_WEBHOOK_URL")
    payload = {"text": message_text}
    
    response = requests.post(
        url, 
        data=json.dumps(payload),
        headers={"Content-Type": "application/json"}
    )
    return response.status_code == 200
```
